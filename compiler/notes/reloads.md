# Step 12 — speed-ups (2026-10-31)

(Read only when working on this part.)

- **Bit tests** (backend-hbc2.c `test_bits`, `bit_cond`): `x & k` with one non-zero byte in k → load that byte (`lod b, <byte>` when x is an ALU operand, else codegen + that register), `and r, k` (`or r, 0` for 0xFF), cc = CC_NZ. Also `(x & k) != 0` / `== 0`, the 0/1 value forms (T_BOOL without CCONLY, compares → cc_value), and `?:` conditions: gen_rewrite_node sets CCONLY on the T_BOOL left of a T_QUESTION (backend.c's codegen_lr handles `?:` before gen_shortcut).
- **`<<=` `>>=`** by a constant (`direct_shifteq`): load, shift_left / shift_right (same limits as direct_shift: long only multiples of 8 or `<< 1`), store; char = k × shl/shr/asr b. `eq_target` (shared with direct_eqop) finds the variable or loads [x:y].
- **Reload removal**: `hbc2/crates/hbc2-cc/src/reloads.rs`, run by `compile()` after copt, before `rename_statics`. Module doc = the rules. Per register a set of equal things (Const, Mem(Sym/Stack/Xy), Same(n)); stack slots keyed by `offset - depth` (depth = bytes pushed); popped slots forgotten (interrupts write below SP). Forget all at labels that are used anywhere in the file or don't start with `__`, after cal/jmp/ret/anything unknown. Removed: `lod` / `mov` whose value the register already has.
- **Volatile**: cc1 `make_symbol` flags volatile variables' nodes SIDEEFFECT (UPSTREAM.md); cc2 `note_volatile` (in gen_rewrite_node) collects `;volatile _name` / `__T` labels, `;volatile stack` (flagged local or a deref of one), `;volatile pointer` (flagged deref of anything else), `;volatile *` (> 32 names). FCC flags every deref once a function has said "volatile" (voltrack): coarse but safe. The copt store-then-load rules were removed (they dropped reloads of volatiles; the pass gives byte-identical code).
- Measured (all test programs): code 657 012 → 636 332 bytes, ticks 1 449 972 → 1 440 436 (bench.c 245 310 → 240 635). Most programs' hot loops start at a label, so ticks move little.
- Tried and left: carrying knowledge across loop labels (would need dataflow; bench.c's loop labels get different values from each path). `lod` → `mov` from a register holding the value: no gain (every instruction is 1 cycle).
- **string.h** in `lib/asm/string.has` (src/string.c removed): [x:y] dest, [i:j] src, [c:d] count tested with `sub d, 1 / sbb c, 0 / jmc` (borrow = was 0). Shared tails: lib_str_dest, lib_str_diff ([a:b] = a - b as ints), lib_str_zero, lib_str_found, lib_str_null, lib_str_end (cal'd: args + 2). 2652 → 1068 bytes; strlen 12 → 6 instructions per char; tests/strings.c 95 317 → 67 133 ticks. Mutation-checked (6).
